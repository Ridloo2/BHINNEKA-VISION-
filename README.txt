BHINNEKA VISION — REOG PONOROGO
================================

Isi ZIP
- index.html : struktur website dan materi Reog Ponorogo
- style.css  : desain responsif untuk HP dan komputer
- script.js  : viewer ilustratif, animasi, kuis, dan tantangan

CARA MEMBUKA DI HP ANDROID
1. Ekstrak file ZIP.
2. Buka folder hasil ekstrak.
3. Buka index.html menggunakan browser. Jika file lokal dibatasi browser, gunakan editor/preview HTML yang sudah kamu miliki.
4. Semua fitur dasar bekerja tanpa server. Tautan sumber eksternal membutuhkan internet.

FITUR
- Asal-usul dengan keterangan bahwa ada beberapa versi legenda.
- Informasi daerah asal Ponorogo, Jawa Timur.
- Viewer interaktif 360° bergaya ilustrasi dengan slider dan penanda bagian.
- Animasi ilustratif gerak pertunjukan.
- Lima soal kuis dengan skor dan pembahasan.
- Empat tantangan pelestarian dengan checklist progres.

CATATAN PENTING TENTANG VISUAL 360°
Viewer yang disertakan adalah visualisasi ilustratif interaktif, bukan model 3D hasil pemindaian atau foto 360° autentik. Slider mengubah sudut tampilan ilustrasi agar prototipe bisa diuji. Untuk visual 360° yang benar-benar memperlihatkan objek dari seluruh sisi, ganti bagian viewer dengan model 3D .glb/.gltf atau rangkaian foto 360° Reog yang kamu punya izin untuk gunakan. Jangan mengklaim ilustrasi ini sebagai dokumentasi asli.

Asal-usul Reog memiliki sejumlah versi. Website ini menyebut dua versi yang dikenal luas tanpa menyatakan salah satunya sebagai satu-satunya kebenaran historis. Peran, busana, dan detail pertunjukan bisa bervariasi antarkelompok.
